# Алгоритмы и структуры данных

Учебные работы разделены по семестрам:

- `1_sem` — работы первого семестра;
- `2_sem` — работы второго семестра.

Во втором семестре реализованы:

- задача о максимальном подмассиве;
- задача о размене монет;
- задача коммивояжёра;
- задача о бросании яиц;
- раскраска графа;
- дискретная задача о рюкзаке;
- задача о раскладке по ящикам.

Для запуска тестов второго семестра:

```bash
cd 2_sem
python3 -m pytest -q
```
